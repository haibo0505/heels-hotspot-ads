# 八大元素 × 说人话

## 元素的用途与区别

| 元素 | 怎么进入选题 | 高跟鞋应用方向 |
|---|---|---|
| 成本 | 钱、时间、精力与选择成本 | 一双鞋搭多套衣服；确有价格证据再做预算题 |
| 人群 | 点名有具体场景的人 | 第一次穿高跟鞋上班、下班直接去聚会；不诊断脚型健康 |
| 奇葩 | 意料外但能理解的道具或行为 | 让鞋当面试官；怪的是剧情，商品展示要真实 |
| 最差 | 从失误、踩雷、反面示范进入 | 模拟“裤脚搭错鞋”的排雷；不捏造竞品差评或全网最差 |
| 头牌 | 可核实的标杆、名场面、风格符号 | 讨论红毯造型逻辑；借风格不冒充明星同款或授权 |
| 荷尔蒙 | 成人之间自愿、尊重的情绪拉扯 | 约会临出门的期待与反转；不靠擦边或贬低女性 |
| 反差 | 本以为A却发生B | 羽绒服发布会被鞋抢主角；年龄/身份跨界本身属于反差 |
| 怀旧 | 真实的旧时光、记忆与遗憾 | 妈妈年轻时的穿搭回忆；有长辈不自动等于怀旧 |

“60分→90分”只是选题包装比喻，不输出伪造打分，不承诺爆量。原题诊断只在对创意决策有帮助时短写，不贬低用户。

## 让口播自然，同时保住广告目的

从已完成且经过事实核对的广告稿开始编辑，不把“去AI味”变成另写一个故事。

- 清理没有信息的预告、重复铺垫和生硬名词化；有信息、关系、条件、评价和情绪的部分保留。
- 数字、时间、SKU、价格条件、比较对象、否定和不确定程度都不能改丢。“搭三套”不能变成“百搭所有衣服”，“这次试穿感受”不能变成人人都舒服。
- 不凭空编一位用户、一次试穿、销售纪录或亲身经历。创意角色可以是虚构的，但不能把其台词伪装成真实买家证言。
- 不因像宣传就全删夸张和反问；有效视觉冲突、节奏与购买引导继续保留。用户说“写平实点”才额外降调，但事实与承诺仍保护。
- 修改用户给定原文时尊重编辑范围；只标问题就不替换全文，只在原位改就不重排。未获授权不重写代码、路径、来源引文或评论区记录。
- 内部比较前后稿，检查谁做什么、动作结果、条件、语气和商品事实是否一致；只交最终可录版本，不输出AI含量、机械打分或自评。

## 结构演示（不是产品实测）
