# Seedance制作适配

可选安装中文版`seedance-prompt-zh`；可用时独立调用并读取其SKILL.md，没有安装也可按本参考完成广告编译。这里只保留广告编译所需约定，不把它2026年资料里的时长、像素、文件数量、人脸限制当成所有平台或未来版本的恒定规则。真正提交前以用户目标平台和版本的当前界面/官方文档确认；没有确认就标明限制待核实，不主动阻止写好文本稿。

主体/人物 → 场景与构图 → 动作阶段与微表情 → 景别/运镜 → 时间轴 → 转场 → 音乐/音效/口播 → 结束状态。

- 同一时间段不能既固定镜头又环绕；每段有具体动作而非堆“高级感”“电影级”。
- 参考图逐一映射用途，明确谁穿哪双鞋；多角度是同一产品时明写“同一双鞋的不同视图”。未知款色、Logo、材质不补造。
- 原视频默认只用于分析，编译成文字动作、镜头和声音说明；没有实际上传就不写`@视频1`或要求生成平台参考原声。只引用用户实际准备的素材。
- 中文口播逐字写，配声音状态、语速与停顿；不靠背景音乐盖住卖点。不模仿未授权真人声线；音乐用可商用来源或原创生成要求。
- 20—30秒广告不强塞给单次15秒模型。先核实当前最大时长；如仅支持15秒，按叙事自然边界拆两段，锁定人、鞋、衣服、光线、运镜方向与承接动作，各段时间从0开始并标注剪辑顺序。支持整段就不机械拆分。
- 默认一条可复制正文，超过平台文本限制才分；不得为省字删掉决定动作连续、商品一致性或口播含义的内容。生成只是创意演示，真实卖点仍需实物证明。

默认写提示词，不付费生成、上传素材或发布；需要这些动作时遵循当前用户授权。
